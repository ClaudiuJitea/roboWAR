# Design assumptions

The four images define art direction. The gameplay rules come from `Godot_Blender_Game_Master_Prompt.md`, not from inferred screenshot behavior. The arena uses one-meter world scale, a 48 × 38 meter floor, static walls and cover, and decorative rail geometry. The large `03` decal uses a 3D label. Heroes are about two meters tall in the generated models; enemies are deliberately simpler. A capped crowd of 85 live enemies and grid path requests keep the arena responsive on the tested machine. These dimensions and counts can be adjusted in the scripts.
